FEATURED PROJECT PHOTOS — homepage "Featured Projects" cards
============================================================

Upload your real project photos into THIS folder
(assets/images/projects/) via cPanel File Manager, using these
EXACT filenames so they appear automatically on the homepage:

  1. marina-tower.jpg           -> "Marina Tower - 52 Floors" card (High-Rise, Dubai Marina)
  2. steel-warehouse.jpg        -> "Steel Warehouse Complex" card (Industrial, JAFZA Dubai)
  3. exhibition-center-dome.jpg -> "Exhibition Center Dome" card (Commercial, Abu Dhabi)

Recommended: landscape JPG, at least 800 x 600 px, under ~300 KB each
(the card crops to a 220px-tall area, object-fit: cover).

Until a file is uploaded, that card gracefully falls back to the
existing green graphic — nothing looks broken.

To change a card's photo, just replace the file (keep the same name)
or edit the <img src="..."> in index.html.
